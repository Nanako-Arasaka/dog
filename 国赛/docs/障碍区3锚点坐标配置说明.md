# 障碍区 3 锚点坐标配置说明

> 用途：把「位姿点 + AprilTag 码」现场采集的坐标，配置进避障用的 `competition_map.yaml`，
> 让 LocalPlanner 沿障碍区 3 锚点（起始/中间/末尾）引导狗逐点推进 + 实时避障。
> 前置：LocalPlanner 已接入正式 ROS 链路（commit 612cd35）。

## 数据流

```
现场标定 AprilTag ──▶ config/tags.yaml（10 个 tag 世界坐标）
现场采集航点     ──▶ waypoints_FINAL.yaml（13 个任务航点）
挑障碍区 3 锚点  ──▶ cone_avoidance/competition_map.yaml（global_path）
```

## 步骤 1：标定 AprilTag 世界坐标

```bash
cd /home/jetson/Desktop/guosai/dog_repo/国赛
python3 tools/calibrate_tags.py --tags-yaml config/tags.yaml
python3 tools/calibrate_tags.py --tags-yaml config/tags.yaml --verify   # ≤10cm/5° 通过
```

产出：`config/tags.yaml` 里每个 tag 的 `world.x / world.y / world.z / yaw_deg`。

## 步骤 2：采集位姿点（13 航点）

```bash
bash scripts/guosai_onekey.sh collect --load-existing-map   # ⚠️ 必须带参数
```

产出：`waypoints_FINAL.yaml`（start_exit → … → finish 的 x/y/yaw）。
巡检点按「观察位姿」采（yaw 朝表），详见 `docs/航点采集现场操作指引.md`。

## 步骤 3：把障碍区 3 锚点填进 competition_map.yaml

障碍区的「起始/中间/末尾」3 个锚点，从已标定的 tag 里选（现有 10 个 tag，不新增）。
对应关系（现场确认）：起始 = 点六（障碍入口）、末尾 = 点七（障碍出口）、中间 = 现场指定（如点八或其他合适 tag）。

编辑 `cone_avoidance/competition_map.yaml`：

```json
{
  "obstacle_zone_rect": {
    "xmin": 0.0, "xmax": 6.0, "ymin": -1.5, "ymax": 1.5
  },
  "global_path": [
    [<起始锚点 world.x>, <起始锚点 world.y>],
    [<中间锚点 world.x>, <中间锚点 world.y>],
    [<末尾锚点 world.x>, <末尾锚点 world.y>]
  ]
}
```

- 坐标从 `config/tags.yaml` 对应 tag 的 `world.x / world.y` 抄（世界系 = SLAM 建图系）
- `obstacle_zone_rect` = 障碍区矩形边界（不超此范围），按场地实际量，当前是占位值
- 全局路径方向：点 1 → 点 2 → 点 3（狗沿此方向推进）

## 步骤 4：验证

```bash
# 确认 LocalPlanner 读到 3 锚点（看日志）
ros2 launch launch/guosai_final.launch.py   # 或跑 cone_avoidance_node 单独验证
# 日志应出现：LocalPlanner ready: path=3 pts rect=[...]
```

障碍区实测：放 2 个随机锥桶，确认狗沿 3 锚点推进、绕桶、不超边界、出口回到导航。

## 注意

- **坐标系铁律**：所有坐标（tag/航点/global_path）都是「建图那次」SLAM 世界系；地图永不重建
- tag 标定与航点采集**必须在同一次 SLAM 会话 / 同一张地图**下完成，否则坐标对不上
- global_path 锚点要**贴着障碍区中轴线**布（起始在入口、末尾在出口附近），中间点放在锥桶带中段
