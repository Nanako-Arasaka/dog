### 0. 一句话方案
以**绝影 Lite2 四足机器人**为本体，背载 **NVIDIA Jetson Xavier NX** 作为感知/决策主机，搭载 **6 自由度机械臂（JetArm）** 与 **Intel RealSense 深度相机**，在 5000×6000mm 的模拟工业巡检场地中，于 10 分钟内自主完成「避障 → 配电柜仪表巡检识别与语音播报 → 抓取红色异常长条并放置到对应字母箱」三项任务。

### 1. 赛事与任务概述
- **比赛场景**：模拟工业巡检，10 分钟正赛。
- **评分构成**：线下挑战 **60%** ＋ 技术文档 **30%** ＋ 线上视频 **10%**。
- **允许设备**：四足本体 ＋ 一块 Nvidia AI 主机（≤ Jetson Xavier NX）＋ 1 个扬声器 ＋ 1 个机械臂（臂展 ≤50cm / 自由度 ≤6 / 重量 ≤2kg）。**禁止使用激光雷达**（违规取消成绩）。
- **三大线下任务**：

| 任务 | 分值 | 内容 |
|---|---|---|
| 避障 | 10 | 障碍区 2 个 67×32×32cm 锥桶，自主绕行通过 |
| 巡检识别 | 40 | 检测区配电柜+变压器贴 A/B/C/D 字母图 + A4 仪表盘；按指针颜色判状态（黄=偏低/绿=正常/红=偏高）；**4 次语音播报**，每次 10 分（字母 5 + 状态 5）；无声但终端有输出仅 2.5 分/次 |
| 长条抓取 | 50 | 抓取区 800×600×500mm 高台上 4 个 100×50×50mm 长条（红=异常/绿=正常）；抓**红色**长条搬运到放置区对应字母 50×50×50cm 纸箱；**抓两次**，每次 25 分（悬空>3s 10 + 跨放置区边界 10 + 正确放置 5） |

- **扣分**：搬运掉落 −5/次（最多 −10，掉 3 次比赛结束）；碰障碍/道具 −5/次（最多 −30）；冲撞不止直接结束。

### 2. 系统总体架构
**硬件拓扑**：Lite2 运动主机（UDP 接收运动指令）◀─UDP── Jetson Xavier NX（感知/决策/播报）─▶ JetArm 机械臂、RealSense（SLAM/避障）、Astra（抓取视觉）、扬声器（音频输出）。

**软件分层（ROS2）**：
```
[感知层]  live_detect_yolo_opencv  → YOLO(zone A/B/C/D + gauge) + OpenCV 仪表读数
                                    → 发布 /bridge/inspection_result, /bridge/placement_zone
[桥接层]  integration_bridge       → 冻结 A/B/C/D → 发布 /inspection/all(FSM用) + /inspection/all_detailed(播报用)
[决策层]  task_manager_node (FSM)  → 编排 START→避障→巡检→抓取→放置 全流程
[执行层]  obstacle_avoidance       → 锥桶 YOLO + 规则避障 vx/vy/wz
          arm_grasp                → 视觉→/vision/grasp_pose→task_manager→arm_control→舵机
          controller               → Lite2 UDP 运动接收 + ORB-SLAM3 + goal_controller
[支撑节点]nodes/                   → localization_watchdog, waypoint_navigator,
                                      motion_mux, cone_avoidance_node, voice_broadcast_node
[集成]   launch/guosai_final.launch.py + config/guosai_final.yaml + scripts/guosai_onekey.sh
```

### 4. 软件模块详述
#### 4.1 巡检识别 `live_detect_yolo_opencv.py`
- **算法**：5 类 YOLO（`zone_A/B/C/D` + `gauge`）+ OpenCV 仪表盘指针角度识别。
- **状态判定**：黄针 → 偏低(low)；绿针 → 正常(normal)；红针 → 偏高(high)。带状态稳定化窗口（history=7，≥4 票才输出）。
- **输出**：`/bridge/inspection_result`，含 `gauge_status: low/normal/high`（**保留三态不做折叠**）。
- **附加**：MJPEG 串流供调试。

#### 4.2 桥接 `integration_bridge/`
- **职责**：订阅 `/bridge/inspection_result`，按区冻结 A/B/C/D（收到即定，4 区齐全后不再变）。
- **双发布**：
  - `/inspection/all`：`abnormal/normal` 形式，供 FSM 用；
  - `/inspection/all_detailed`：`low/normal/high` 三态，供播报节点用。
- **放置区**：`/bridge/placement_zone` → `/placement/recognized_zone`。

#### 4.3 避障 `obstacle_avoidance/`
- 单类 YOLO 检 `cone`，纯规则避障（按 bbox 位置/面积输出 `vx/vy/wz`），UDP 发狗端。
- **仅在障碍区启用**（受 `/motion/enable_cone_avoidance` 门控，离开即关闭）。

#### 4.4 机械臂抓取 `arm_grasp/`
- Hiwonder JetArm 6DOF + Astra + 手眼标定 `cam2arm = (x=0.255, y=-0.06, z=-0.55)`。
- 直抓流程（Jetson 跑通）：z 轴 Δz>0.03m 抓取验证、10 次重试定向转底座、4 次失败回退、边缘微调仅首触、防重复指令。
- 链路：`视觉检测 → /vision/grasp_pose → task_manager → arm_control → 舵机`。

#### 4.5 控制 `controller/`
- Lite2 UDP 运动接收器（带 watchdog）+ ORB-SLAM3 + ROS2 `goal_controller` 目标点控制。

#### 4.6 任务状态机 `arm_grasp/arm_grasp/task_manager_node.py`（575 行 FSM）
- 状态链：`WAIT_LOCALIZATION → GO_START → GO_OBSTACLE_ENTRY → OBSTACLE_ZONE(开避障) → GO_INSPECTION×N → WAIT_INSPECTION(等四区齐全) → GO_PICK → GRASP → GO_PLACE(按异常字母选箱) → PLACE → 循环第二异常区 → GO_FINISH → DONE`。
- 容错：机械臂 3 次重试、巡检 45s 总超时/每航点 5s、定位丢失急停、避障优先仲裁。

#### 4.7 语音播报 `nodes/voice_broadcast_node.py`
- 订阅 `/inspection/all_detailed`，按 **A→B→C→D** 固定顺序播放 `{zone}_{state}.wav`（12 个预录音频，macOS `say` 合成）。
- 防重播：同一冻结结果只播一次；`/competition/state` 回到 `WAITING_INSPECTION` 时重新武装，支持多轮。
- 播放器 `MiniSpeaker`（mock / aplay / ffplay），`device` 参数指定声卡（指向狗自带扬声器或外置 USB）。

#### 4.8 支撑节点 `nodes/`
- `localization_watchdog`：定位稳定性判定 + 丢失急停。
- `waypoint_navigator`：航点导航。
- `motion_mux`：速度指令仲裁（避障优先于导航）+ UDP 下发 + 超时保护。
- `cone_avoidance_node`：避障 ROS 节点，受 topic 门控。

---

### 5. 核心算法
1. **仪表读数**：OpenCV 提取指针主轴角度，按阈值分区映射偏低/正常/偏高，稳定化窗口去抖。
2. **巡检冻结**：以区为键，首次有效结果即锁定，4 区齐后定稿（防抖动误判）。
3. **手眼标定**：相机→臂基 `cam2arm` 齐次变换，像素坐标→机械臂基坐标。
4. **SLAM 导航**：ORB-SLAM3 RGB-D 建图 + 航点（waypoints）顺序导航。
5. **任务编排 FSM**：事件驱动状态转移，超时/重试/急停兜底。

### 7. 容错与鲁棒性
- 定位丢失 → localization_watchdog 急停。
- 机械臂抓取失败 → 3 次重试 + 回退。
- 巡检超时 → 以当前异常区继续，不卡死。
- 避障优先级高于导航（motion_mux 仲裁），避免误避。
- 语音防重播 + 多轮重新武装。
