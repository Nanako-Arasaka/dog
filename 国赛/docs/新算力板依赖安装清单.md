# 新算力板依赖安装清单（国赛完整版）

> 生成日期：2026-08-17
> 适用范围：任何全新算力板（Jetson Orin NX / Xavier NX / 其他 ARM64 或 x86 板卡），已通读全仓库代码与配置文件逐项核对。
> 系统基线：Ubuntu 22.04 + Python 3.10 + ROS2 Humble（Jetson 场景为 JetPack 5.x，自带 Python 3.8/3.10 视版本而定，本项目按 3.10 编写）。

### pip 一键安装（基础版）

```bash
# ARM64 / Jetson 注意：torch 不要用 pip 默认源（装的是 x86 轮子会失败），
# 先按第四步装 NVIDIA 官方 torch，再装其余：
python3 -m pip install numpy opencv-python PyYAML pyserial Pillow pytest \
  ultralytics pyorbbecsdk openni pyrealsense2 PyMuPDF
```

> ⚠️ **AprilTag（2026-08-17 起规则禁用，全部不装）**：`config/guosai_final.yaml` 的 `tag_localizer.enabled/fallback_enabled` 已置 `false`，`tag_localizer_node` 不启动，因此**不需要** `dt-apriltags`、`libapriltag-dev`、AprilTag 打印码。若历史环境里装过 `apriltag`/`dt-apriltags`，建议卸载以免误用：
> ```bash
> pip uninstall -y apriltag dt-apriltags 2>/dev/null || true
> ```

## 二、ROS2 Humble 本体（apt）

新板子必须先把 ROS2 Humble 装好（项目所有节点基于 rclpy）：

```bash
sudo apt update
sudo apt install -y ros-humble-desktop   # 或最小化：ros-humble-ros-base
```

核心 Python 依赖 `rclpy`、`std_msgs`、`geometry_msgs`、`sensor_msgs`、`nav_msgs`、`std_srvs` 随 desktop 自带。额外需要：

```bash
sudo apt install -y \
  ros-humble-cv-bridge \
  ros-humble-realsense2-camera \
  ros-humble-launch ros-humble-launch-ros \
  ros-humble-ament-index-python \
  python3-colcon-common-extensions
```

- `realsense2_camera`：正式链路启动命令 `ros2 launch realsense2_camera rs_launch.py`（config/guosai_final.yaml）
- `cv_bridge`：ROS 图像↔cv2 转换（live_detect、astra_camera_node 等 7 处）
- `launch` / `launch_ros` / `ament_index_python`：`launch/guosai_final.launch.py` 与 arm_grasp launch 文件依赖

## 四、ORB-SLAM3（C++ 源码编译，定位核心）

仓库 `controller/ORB_SLAM3/` 只有 C++ 源码（`src/`），**没有** CMakeLists.txt、**没有** Thirdparty（DBoW2/g2o/Sophus）、Vocabulary 只有 42MB 压缩包。新板子上必须：

1. 从官方仓库拉取完整 ORB_SLAM3（含 Thirdparty）编译，或把旧板 `/home/jetson/ORB_SLAM3`（已编译版）整个拷过来；
2. 编译 ROS2 wrapper（`ros2 run orbslam3 rgbd` 由 config 引用）；
3. 解压 `controller/ORB_SLAM3/Vocabulary/ORBvoc.txt.tar.gz` 得到 139MB 词汇表（或指向旧板已解压的 `/home/jetson/ORB_SLAM3/Vocabulary/ORBvoc.txt`）。

C++ 依赖（apt / 源码）：

```bash
sudo apt install -y build-essential cmake git \
  libeigen3-dev libboost-all-dev libglew-dev libssl-dev \
  libeigen3-dev libopencv-dev  # Pangolin / g2o / Sophus / DBoW2 需从源码编译（Pangolin 也可 apt 装 ros 依赖里的）
```

## 七、一键安装脚本（推荐，替代手抄下面所有命令）

仓库已内置一键脚本 `scripts/setup_new_board.sh`，自动完成：仓库拉取 → 系统依赖(apt) → ROS2 Humble → Python 依赖(pip) → 仓库自带包 colcon 编译 → ORB 词汇表解压/检测 → 数据校验 → preflight 自检。幂等可重跑。

```bash
# 在已拉取好的仓库内运行（会自动 git pull + 安装一切）
bash scripts/setup_new_board.sh

# 完全从零开始（自动 clone 仓库 + 安装）
bash scripts/setup_new_board.sh --repo https://github.com/Nanako-Arasaka/dog.git

# Jetson JetPack 6 手动指定（默认自动检测）
bash scripts/setup_new_board.sh --jetpack 6

# 已装过 ROS2 / 不编译机械臂 / 需要 ORB-SLAM3 全自动编译时
bash scripts/setup_new_board.sh --skip-ros --no-arm --build-orbslam3

# 全程自动确认（无人值守）
bash scripts/setup_new_board.sh --yes
```

> 脚本细节：
> - Jetson aarch64 的 torch 走 NVIDIA 官方 wheel（`--jetpack 5|6` 切换源），装失败会给出官方文档指引且**不会中断脚本**
> - AprilTag 相关全部不装（规则禁用）：不安装 `dt-apriltags` / `libapriltag-dev`，`config` 的 tag_localizer 段已置 false
> - 自动创建 `~/ros_robot_controller_sdk.py` 软链（机械臂串口桥接依赖，对应 `run_guosai_final.sh` 的 PYTHONPATH 约定）
> - 机械臂 msgs/ros_robot_controller 按 `arm_grasp/readme.md` 的嵌套包 workaround 分步编译
> - ORB-SLAM3 默认只检测+解压词汇表（仓库内无 Thirdparty/CMake），需 `--build-orbslam3` 才自动编译

## 八、安装顺序建议（手动版，脚本的等价展开）

```bash
# 1. 系统依赖
sudo apt update
sudo apt install -y build-essential cmake git libeigen3-dev libboost-all-dev \
  alsa-utils ffmpeg

# 2. ROS2 Humble（若未装）
sudo apt install -y ros-humble-desktop
sudo apt install -y ros-humble-cv-bridge ros-humble-realsense2-camera \
  ros-humble-launch ros-humble-launch-ros ros-humble-ament-index-python \
  python3-colcon-common-extensions
source /opt/ros/humble/setup.bash

# 3. NVIDIA 官方 torch（Jetson aarch64 必用，勿用 pip 默认源）
#    JetPack 5.x 对应 torch 2.x wheel：从 NVIDIA 官方下载安装
pip install numpy opencv-python PyYAML pyserial Pillow pytest PyMuPDF
pip install ultralytics
pip install pyorbbecsdk openni pyrealsense2

# 4. colcon 编译仓库自带包（见第三节）
# 5. ORB-SLAM3 完整编译（见第四节）
# 6. 拷贝模型 / 地图 / 音频（见第六节）
# 7. 验证：python3 scripts/preflight_guosai_final.py --config config/guosai_final.yaml --root $(pwd)
```
